# GATE CSE Tracker

Mock analysis, mistake log, spaced revision, todo + pomodoro. PYQs and custom mocks are done on GateQA; results are logged here.

```
npm install
npm run dev      # local
npm run build    # static site in dist/ — host on Netlify / Vercel / GitHub Pages
```

Subjects and GateQA/GateOverflow links: `data/gate-cs.json`.

Data is stored in the browser. To keep it safe and portable, open **Settings & Sync** and link a JSON file
(Chrome/Edge/Brave) — every change is auto-saved to it, no backend needed. Put that file in Google Drive,
Dropbox or a git repo to sync across devices.
